# CodeAlpha Phishing Awareness Training

## Cyber Security Internship – Task 2

### Project Overview

This project was completed as part of the CodeAlpha Cyber Security Internship.

The objective of this project is to create awareness about phishing attacks and educate users on how to identify and avoid phishing attempts.

## Topics Covered

- What is Phishing?
- How Phishing Works
- Types of Phishing
- Identifying Phishing Emails
- Identifying Fake Websites
- Social Engineering
- Social Engineering Techniques
- Real-World Phishing Example
- Phishing Prevention
- What to Do After Clicking a Phishing Link
- Interactive Quiz

## Tools Used

- Microsoft PowerPoint
- GitHub

## Project File

The complete presentation is available in this repository:

`Phishing_Awareness_Training.pptx`

## Learning Outcome

This project helped me understand common phishing techniques, social engineering methods, warning signs of phishing attacks, and basic prevention practices.
